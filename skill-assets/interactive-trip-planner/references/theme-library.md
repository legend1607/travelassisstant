# 旅行主题库

主题候选不能只覆盖城市、艺术、吃喝和夜生活。目的地有海岛、热带、山地、自然或宗教文化资源时，必须把这些体验纳入候选。

## 主题生成原则

- 给 3-5 个候选主题，不要只给一个默认主题。
- 主题要像“路线叙事方案”，不仅说路线类型，还要写会经过哪些地方和每段叫什么。
- 每个主题说明强化什么、牺牲什么、适合什么节奏。
- 主题可以组合，例如“白天高迪建筑，晚上世界级酒吧”。
- 主题必须能指导地点取舍、酒店区域、每日锚点和地图类别。
- 主题必须吸收在地语境：当地历史、移民/宗教/产业线索、街区生活、季节性体验和旅行日期内的节庆活动。不要只把主题写成景点类型。

## 行程段命名

给每个重要城市、岛屿、街区或自然区域一个可记忆的段落名。名称应该帮助用户一眼理解这一段的体验，而不是普通地名堆叠。

示例：

- 里斯本《山城日常》：坡道、电车、瓷砖立面、社区市场、咖啡店和港口城市历史。
- 仙本那《水之呼吸》：潜水、浮潜、离岛、船程、海况和潜水后飞行缓冲。
- 巴塞罗那白天《高迪的梦幻建筑》：圣家堂、米拉之家、巴特罗之家、Eixample 网格。
- 巴塞罗那夜晚《世界级酒吧半径》：tapas、vermut、cocktail bar 和夜间安全回程。
- 纳帕《缓慢品饮的山谷》：酒庄预约、驾驶顺序、午餐和品饮强度。

避免：

- 只写“城市 + 景点线”。
- 使用和地点无关的空泛词，例如“梦幻之旅”“品质路线”。
- 名称太华丽但不能指导取舍。

## 通用主题类型

### 城市初访核心

适合第一次去大城市。强化必看景点、经典街区、代表性博物馆和稳定交通。牺牲冷门远点和过多餐厅跳转。

### 艺术建筑线

强化建筑、博物馆、画廊、设计酒店和空间体验。适合巴黎、巴塞罗那、东京、墨西哥城等。

### 吃喝夜生活线

强化餐厅、bar hopping、wine/cocktail、市场、小吃和夜间安全半径。牺牲过早起床和远距离 day trip。

### 本地生活和街区线

强化市场、咖啡、社区街区、公园、小馆和生活动线。牺牲部分“必打卡”密度。

### 海岛和潜水线

适合东南亚、海岛、珊瑚礁、潜水目的地。强化潜水、浮潜、船宿、离岛、海况、季风、潜点交通、潜店资质和休息日。

使用前必须确认：

- 是否会游泳。
- 是否有潜水证，例如 Open Water / Advanced Open Water。
- 想 scuba diving、free diving、snorkeling 还是只想海边放空。
- 是否接受船程、晕船、早起和连续下水。
- 旅行月份是否处于适合海况和能见度的季节。
- 是否需要安排潜水后 18-24 小时不上飞机的缓冲。

### 热带雨林和野生动物线

强化雨林、国家公园、野生动物、夜游、河流、向导和生态住宿。需要评估雨季、蚊虫、体力、安全和交通。

### 火山山地和户外线

强化火山、徒步、日出、温泉、山地小镇和自然景观。需要确认体力、装备、海拔、天气和是否接受早起。

### 宗教文化和历史线

强化寺庙、清真寺、教堂、殖民历史、移民史、仪式和节庆。适合马六甲、京都、伊斯坦布尔、清迈等。

### 南洋旧梦 / 移民史线

适合马六甲、新加坡部分街区、怡保等。强化华人移民史、骑楼、会馆、庙宇、咖啡店、旧城街市、娘惹/南洋饮食和港口城市记忆。

### 海边度假和恢复线

强化酒店、沙滩、spa、日落、轻餐、低移动成本和休息。牺牲景点密度和跨区探索。

### 亲子省力线

强化低强度、确定性、休息、厕所/餐饮/交通便利和可替换方案。牺牲夜生活和高不确定排队项目。

## 东南亚主题提醒

规划印尼、马来西亚、菲律宾、泰国、越南海岸、斯里兰卡等目的地时，主题候选至少考虑以下方向中的相关项：

- 潜水 / 浮潜 / 海岛跳岛
- 雨林 / 野生动物 / 国家公园
- 火山 / 山地 / 温泉
- 南洋旧城 / 移民史 / 殖民街区
- 夜市 / 小吃 / 咖啡店 / hawker center
- 寺庙 / 清真寺 / 宗教和节庆
- 海边度假 / spa / 恢复型旅行

如果用户没有提到潜水，但目的地是典型潜水或海岛目的地，不要默认安排潜水；把它列为主题候选并先问用户是否有兴趣和资质。
