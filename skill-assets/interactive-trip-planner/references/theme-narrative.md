# 路线叙事和行程段命名

主题候选应该帮助用户一眼知道这趟旅行“会经过哪里、每段在体验什么、为什么这样取舍”。不要只输出普通路线类型。

## 输出结构

每个主题候选用以下结构：

```text
1. 《主题名》
经过：城市/岛屿/街区/自然区域
行程段：
- 《段落名》：地点，核心体验。
- 《段落名》：地点，核心体验。
- 《段落名》：地点，核心体验。
强化：这条路线会优先安排什么。
牺牲：这条路线会放弃或降级什么。
适合：适合的用户偏好、体力和节奏。
```

## 命名原则

- 名称要来自目的地真实体验：历史、移民、建筑、海况、食物、夜生活、地形、交通或材料。
- 名称要能指导路线，不只是好听。
- 每段名不要太长，最好 4-8 个汉字或一个短语。
- 不要套用所有目的地通用词，例如“经典之旅”“深度体验”“梦幻路线”。

## 示例

葡萄牙 + 西班牙：

```text
1. 《山城日常与海岸光线》
经过：里斯本 -> 塞维利亚 -> 巴塞罗那
行程段：
- 《山城日常》：里斯本，坡道、电车、瓷砖立面、市场和社区酒馆。
- 《橙花夜行》：塞维利亚，王宫、老城、弗拉门戈和夜间小馆。
- 《建筑与杯中夜色》：巴塞罗那，现代主义建筑、市场、海岸和短半径酒吧路线。
强化：城市历史 + 海岛水下体验 + 恢复型度假。
牺牲：会压缩吉隆坡城市停留和高强度跨岛跳转。
适合：想要文化记忆和海岛体验都保留，但不把每天排满的人。
```

巴塞罗那：

```text
1. 《高迪白日与世界级酒吧夜晚》
经过：Eixample -> Gracia -> El Born
行程段：
- 《高迪的梦幻建筑》：圣家堂、米拉之家、巴特罗之家和 Eixample 城市网格。
- 《社区广场与咖啡》：Gracia，广场、咖啡、轻餐和本地生活。
- 《世界级酒吧半径》：El Born/Eixample，tapas、vermut、cocktail bar 和安全回程。
强化：建筑主线、街区生活、夜间饮酒体验。
牺牲：远郊 day trip 和过多正式餐。
适合：喜欢艺术建筑、街区散步和酒吧的人。
```

巴西：

```text
1. 《海湾、瀑布与巴西节奏》
经过：Rio -> Iguaçu -> Salvador
行程段：
- 《海湾开场》：Rio，海滩、山海视角、城市节奏。
- 《水雾剧场》：Iguaçu，瀑布、边境自然和低强度恢复。
- 《非洲-巴西回声》：Salvador，老城、音乐、宗教和 Bahia 饮食。
强化：第一次到巴西的代表性城市与自然记忆。
牺牲：Amazon/Pantanal 这种更硬核自然线。
适合：第一次去巴西，想要城市、自然和文化都保留的人。
```
