# Barcelona Modernisme Night Atlas

## 样本治理

- 样本类型：owner 确认的代表性规划。
- 代表理由：当前数据用 2 个 market、1 个 food 与 2 个 bar，加上行程中的 local-food、market 和 nightlife 角色，提供“地方风味与夜间半径”的最低代表证据；它能证明市场、地方小吃和短半径夜间收束的组合方式，但不声称已经覆盖完整的 food-first 店型或每个餐次。
- 授权：维护者已确认可作为公开 skill 与 REDSkill 的模型样本复用。
- 脱敏：只包含公开地点与规划级信息，不包含私人住宿地址、订单、联系方式、精确轨迹或同行人身份。
- 证据边界：它是用于表达规划品味的公开样本，不声明实际执行经历。

## 样本定位

巴塞罗那样本代表“艺术建筑 + 市场 + 地方小吃 + 夜生活”的城市旅行。它用高迪、Eixample、老城市场、一个地方小吃点和 cocktail bar 构成白天/夜晚双主线，适合测试市场到夜间的角色分层、短半径夜生活和资源抽屉图片预览。它是当前 food/nightlife 模板的最低代表锚点，不替代未来更完整的 food-first 样本。

## 行程主线

- 主题名：高迪昼行，夜色入杯。
- 行程段命名：
  - D1：Eixample 的建筑开场
  - D2：高迪核心日
  - D3：老城市场与艺术
  - D4：当代美术和夜生活
- 默认节奏：4 天 3-4 晚，酒店锚点在 Eixample / Passeig de Gracia 一带，降低白天景点和夜间回程的复杂度。

## 这个 sample 要测试什么

- 预约型景点如何成为硬约束。
- 白天建筑、博物馆和晚上酒吧如何分层显示。
- 同一 POI 如何同时拥有“为什么去 / 怎么安排 / 注意点”。
- 资源抽屉如何服务视觉强 POI：建筑图片、官网、地图、订票入口。
- 必去/优先去/顺路可去如何影响路线重排。

## 设计方向

视觉语言参考 Modernisme、trencadis 马赛克、铁艺曲线、地中海色和 Barcelona 当代酒吧识别。地图必须保持清晰，装饰只进入 marker、路线线、badge、popup 边框和抽屉标题，不做满屏马赛克背景。

## 待复核

- Sagrada Familia、Park Guell、Casa Batllo 等票务和时段。
- 博物馆闭馆日、临展和晚间开放。
- 酒吧订位、排队和排名信息。
- 旅行日期内的节庆、示威、重大赛事和交通临时管制。
