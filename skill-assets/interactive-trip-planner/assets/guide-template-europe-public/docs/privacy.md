# 公开母版隐私规则

这套母版直接复制私人欧洲地图的交互壳、布局与样式，但内容层只使用明确指定的 `europe-autumn-2026-sample` 白名单数据。构建时整段替换数据区，而不是对私人文本做零散搜索替换。

允许进入母版：

- 公共地点、公共活动和官方来源。
- 片区级住宿示例。
- 不带班次、订单和个人身份的交通说明。
- 通用的预算、体力、安全、预约和复核提示。

不得进入母版：

- 姓名、设备目录和私人地址。
- 航班号、订单号、房源号、入住信息和私人备注。
- 原攻略的日期、存储名称、状态和自由文本。
- 无法确认授权的本地图片。

每次更新后运行 `node scripts/test-europe-public-template.js`。测试会检查独立存储名称、日期数量、关键交互和常见私人信息模式。

公开包检查范围包括单文件 HTML、Leaflet vendor、公开 JSON、来源和线上逻辑文档；privacy 文档本身因需要描述禁用模式而单独排除。发布文件不得出现：

- `file://` 或 `/Users/` 等本机路径。
- 私人攻略的 storage key、旧 trip slug 或数据版本。
- 航班/订单/房源标识、个人地址和仅存在于原攻略的自由文本。

生成单文件 HTML 后必须重新运行隐私测试，保证 JSON 安全不等于构建产物自动安全。派生攻略也必须使用自己的 slug 与 storage key，不能读取公开样例或其他攻略状态。
