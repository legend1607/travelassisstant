## Map-first 原则

- 地图底图、道路/地形/水域、POI 相对位置、marker、路线和筛选控件必须是主角。
- 在地视觉元素只进入整体色调、marker 样式、路线线、popup、侧栏、资源抽屉、badge、边框和状态表达。
- 不要把地图做成海报、手账、画册或装饰插画。

## 禁止事项

- 不要只套国旗色或旅游局海报色。
- 不要堆叠和目的地无关的渐变、贴纸或装饰元素。
- 不要让设计风格压过底图、道路、POI 相对位置、marker 和路线。
- 不要让视觉元素压过筛选、路线编号、popup 信息和移动端可读性。
