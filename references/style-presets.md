# 视觉风格预设

风格视为可替换模块，按以下顺序决定：

1. 用户明确要求；
2. 用户提供的参考图或指定风格；
3. 发布平台与使用场景；
4. 中性编辑设计作为默认值。

## 预设风格

### 中性编辑风
- 清晰网格、克制配色、简洁地图、大量留白
- 配色：黑/白/灰 + 单一强调色
- 字体：无衬线，中等字重
- 适用：信息密度高的总览图

### 旅行手帐风
- 纸张纹理、手绘线条、少量照片碎片和手写强调
- 配色：暖色调，做旧纸张感
- 字体：手写体 + 衬线体
- 适用：每日行程卡、封面

### 极简 Zine 风
- 稀疏纸张海报、小型视觉簇、实验字体
- 配色：单一高饱和色 + 黑白
- 字体：实验性衬线或无衬线
- 适用：封面海报

### 现代信息图风
- 强信息层级、几何图标、明确颜色编码
- 配色：多色编码，高对比度
- 字体：无衬线，多层字号
- 适用：总览图、手机行程卡

### 清爽可爱风
- 柔和形状与活泼图标，保持成人审美
- 配色：马卡龙色系
- 字体：圆润无衬线
- 适用：每日行程卡

### 高级旅行杂志风
- 艺术指导摄影、精致衬线与无衬线字体组合
- 配色：克制，黑白为主 + 一个暖色
- 字体：衬线标题 + 无衬线正文
- 适用：封面海报

## 参考图处理

把参考风格拆解为视觉属性，不得逐字模仿某一具体作品：

- 画布比例与纸张
- 留白和构图
- 字体类别与层级
- 配色与强调色
- 插画、摄影或地图表现方式
- 纸张、印刷、颗粒或数字质感
- 氛围和信息密度
- 明确的反向约束

参考图只控制风格层。路线顺序、标签、方向和信息层级必须保持不变。

## 多风格并行

用户要求多种风格时，为每种风格编译并生成一张独立图片。事实层和信息层不变，只替换风格层。
